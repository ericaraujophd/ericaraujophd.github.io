# Data-Oriented Agent-based Model of Polarization and Fracture in Kenyan Society

**Students:** Adam Byle, Alayna Smith
**Supervisor:** Eric Araújo
**Term:** Fall 2026 to Spring 2027
**Status:** In progress

## Abstract

The problem of political polarization and fracturing in communities is not contained in the north hemisphere. Countries such as Kenya, Brazil, Argentina, India, Oman, among many others also struggle to navigate a new age where technology has taken a prominent role in the spread of information faster and less reliably. To describe this phenomena through one lenses would be a reductionist approach, requiring that each culture, country, or context be studied on its own. A previous agent-based model has been created to provide a broader overview of political polarization in communities, without investing much time into the inner characteristics of each context.

The main goal of this project is to extend the generic model created and apply it to the scenario of Kenya. Students will (1) read and learn about Kenya's background, and how polarization has been observed in there, (2) collect data from reliable sources about Kenya's political, religious, and socioeconomical aspects to inform the model, (3) provide a plan for tailoring the generic model towards a more robust and specific model for Kenya, (4) build a datawarehouse to support decision making and the model, and (5) develop a data-oriented agent-based model where the rules for the agents will be better informed by data analysis and machine learning algorithms.

The final product is a system where experiments can be run and results can be analysed for the Kenyan context.
