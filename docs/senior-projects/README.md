# Senior project summaries

One file per project, named after the entry's `id` in `data/students.json`.
Structure: title, metadata block (students, supervisor, term, status), one Abstract.
Keep each summary to one page. The title (first line) is copied into the
`project` field of the matching entry in `data/students.json`.
When a summary is ready, set that entry's `document_path` to
`docs/senior-projects/<id>.md` so the CV and site builds can pick it up.
Originals of earlier drafts live in `_originals/`.
